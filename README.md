# Pilltalk Desktop downloads

[Download the latest Windows STAGING installer](https://github.com/musokay01-commits/pilltalk-desktop-downloads/releases/latest/download/Pilltalk-Desktop-Staging-Setup.exe)

This repository contains desktop installers, checksums and testing instructions.
The application source is maintained separately in a private repository.

The STAGING app selects its test environment automatically. Install it, sign in
with your staging Pilltalk login, pair Patient and Staff WhatsApp, and connect
Uniphar or continue without suppliers. The app requires installed Google Chrome.

The permanent download link follows the latest verified staging release.
Earlier releases remain available from [Releases](https://github.com/musokay01-commits/pilltalk-desktop-downloads/releases).
Each release includes SHA256SUMS.txt, build-info.json and WINDOWS_TESTING.txt.

Install over the same Staging app to preserve saved connections and pending work.
The installer is currently unsigned. Native Windows messaging and supplier
acceptance are owner-led checks; automated packaging does not establish them.

Staging releases are for testing. A production installer will be identified
separately when that release is authorised.
